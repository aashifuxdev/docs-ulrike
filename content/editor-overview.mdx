Document360's block-based article editor gives you a flexible, structured way to write and format documentation. Every piece of content — a heading, a paragraph, an image, a code sample — lives in its own discrete block, making it easy to rearrange, style, and build rich articles without touching any markup directly.

## Block types

The editor supports a wide range of block types to cover every documentation need.

<CardGroup cols={2}>
  <Card title="Text & Headings" icon="heading">

  <Card title="Lists" icon="list">

  </Card>
  <Card title="Code" icon="code">

  </Card>
  <Card title="Media" icon="image">

  <Card title="Advanced" icon="table-columns">

  </Card>
</CardGroup>

## Toolbar

When you select any text in the editor, a floating toolbar appears directly above your selection. Use it to apply **bold**, *italic*, underline, hyperlink, or inline code formatting with a single click. The toolbar disappears automatically when you click away.

To insert a new block, hover over any existing block and click the **+** button that appears on its left edge. A block-type picker opens, letting you choose exactly the block you want to add at that position.

<Tip>
  Type `/` anywhere on an empty line to open the slash command menu and insert a block without reaching for the mouse.
</Tip>

## Adding code blocks

<Steps>
  <Step title="Open the block picker">
    Click the **+** button on the left side of any block, or type `/` on an empty line to open the command menu.
  </Step>
  <Step title="Choose Code block">
    Search for or scroll to **Code block** in the picker and select it.
  </Step>
  <Step title="Select a language">
    Click the language label in the top-right corner of the new code block and choose your language from the dropdown. Document360 supports syntax highlighting for over 100 languages.
  </Step>
  <Step title="Enter your code">
    Click inside the block and type or paste your code. The editor applies live syntax highlighting as you type.
  </Step>
</Steps>

## Keyboard shortcuts

Speed up your writing with these built-in shortcuts.

| Action | Shortcut |
|---|---|
| Bold | `Ctrl+B` |
| Italic | `Ctrl+I` |
| Heading 1 | `#` + Space |
| Heading 2 | `##` + Space |
| Bulleted list | `-` + Space |
| Numbered list | `1.` + Space |
| Horizontal rule | `---` + Enter |

## Saving your work

The editor autosaves your article every 30 seconds, so you never lose progress from an unexpected interruption. You can also save manually at any time by pressing **Ctrl+S** (or **Cmd+S** on macOS). A timestamp in the top bar confirms when the article was last saved.
